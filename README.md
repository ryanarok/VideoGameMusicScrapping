# Khinsider Album Downloader

This is a funcionality that will let you download an entire album from [Khinsider](https://downloads.khinsider.com/) for free.

## Usage

**Windows:**
    Download `scrap.exe` in the releases and execute it

**Linux:**
    Download `scrap` in the releases and execute it

**Python:**
    Download `scrap.py` and run `python3 ./scrap.py` in the folder
